# CDNダウンロードカウンタ

Issue #252 で追加した、`cdn.php` の `release/*` 配信数を集計する仕組みです。

## 記録対象

- 正規化後の `f` が `release/` で始まるファイル
- CDNまたはローカルキャッシュから正常な内容を取得できた `GET` リクエスト
- IPアドレスや `run` などの追加クエリーパラメータは保存しない

CDN取得が404や不正な内容で失敗した場合は記録しません。カウンタDBへの書き込みは250msだけロック解除を待ち、それでも書き込めない場合はそのリクエストの記録を見送ってCDNレスポンスを継続します。

## DB

`n3s_config.ini.php` の `$n3s_config['dir_data']` を使い、未指定時はリポジトリの `data/` を使います。

- `dlcounter-logs.sqlite`: ファイル、バージョン、時刻をリクエストごとに追記する生ログ
- `dlcounter-main.sqlite`: 日付・時間帯・ファイル・バージョン別の集計値

通常のメインDBやログDBとは分離されています。

## 定期集計

次のコマンドを1時間に1回程度 cron から実行します。

```sh
just cdn-download-count
```

集計開始時点の最大 `log_id` までを対象にし、2つのSQLiteを `ATTACH DATABASE` で接続します。集計開始時に `BEGIN IMMEDIATE` で書込権を確保し、集計値の加算と処理済み生ログの削除を同じトランザクションで行います。失敗時は両方がロールバックされます。集計中のCDNアクセスは短時間ロック解除を待ち、書き込めた生ログは次回の処理対象になります。

## ダッシュボード

管理者でログインし、次のURLを開きます。

```text
index.php?action=dlcounter
```

直近7日、当月、当年、日別、時間帯別、バージョン別、ファイル別のダウンロード数と、未集計ログ数を確認できます。

- 月別ダウンロード推移は、記録開始以降の全期間を表示する。ダウンロードが無い月も0件として含める。
- 週別ダウンロード推移は、月曜始まりで直近52週を表示する。ダウンロードが無い週も0件として含める。
- `release/wnako3.js` は、バージョン別の月次推移も表示する。
- 当月・当年の集計対象は `Asia/Tokyo` の暦月・暦年である。
